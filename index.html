Command Library

Type "/" in any channel to browse them all. Here are the community favorites.

/setup Interactive setup wizard for moderation, logging and welcome channels.
/warn @user reason Issue a tracked warning; escalation actions trigger automatically.
/timeout @user 10m Temporarily mute a member with an optional public reason.
/purge 50 Bulk delete recent messages, optionally filtered by author or bot.
/play song name Search and play a track or playlist in your current voice channel.
/queue Show the upcoming tracks with pagination and jump links.
/filter bassboost Apply audio filters like bassboost, nightcore or 8D in one tap.
/rank @user Show a member's level card with XP progress and leaderboard rank.
/leaderboard xp Server-wide top 10 with weekly, monthly and all-time views.
/rewards add Grant roles automatically when members reach a level.
/poll question Create an instant reaction poll with optional multiple choices.
/remind me in 2h Set personal or channel reminders so nothing gets forgotten.
/ticket open Open a private support ticket with transcript on close.

Frequently Asked Questions

Is Harmony free to use?

Yes. Every core feature is free forever. An optional premium tier adds cosmetic extras like custom rank card backgrounds and bigger playlists.

What permissions does the bot need?

The invite link requests only the permissions required for the features you enable. You can safely add it first and fine-tune channel overrides later.

Can I disable modules I don't need?

Absolutely. Use /modules to toggle moderation, music, leveling or utilities on and off per server. Disabled modules consume no resources.

Does the bot work with large servers?

Yes. Harmony shards automatically and serves communities of any size — our largest server has over 200,000 members.

How is my data handled?

We store only what is needed for features you enable (levels, warnings, settings). Server owners can export or erase all data anytime with /data.

Can I suggest new features?

Please do! Join the support server and drop ideas in the suggestions channel — the roadmap is largely community-driven.

Where can I get help?

Join our support server linked in the footer, or run /help for inline documentation of every command.
